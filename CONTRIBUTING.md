# Contributing

Contributions that improve documentation, portability, validation, and reproducibility are welcome.

## Before opening a pull request

1. Create a focused branch from the current default branch.
2. Avoid committing image data, protected health information, private paths, participant information, or proprietary files.
3. Open the notebook in a clean Mathematica kernel and evaluate it from top to bottom.
4. Confirm that documentation accurately reflects any behavioral change.
5. Describe the Mathematica and ExifTool versions used for testing.

## Notebook changes

Notebook diffs can be difficult to review. Keep changes narrowly scoped and explain which cells changed. For code changes, include a plain-language rationale and before/after behavior in the pull request.

By contributing, you agree that your contributions will be licensed under the Apache License, Version 2.0.

## Reporting problems

Use the GitHub issue templates and provide reproducible, sanitized information. Never attach sensitive thermal images or participant data to a public issue. Security concerns should be sent privately to candan@asu.edu.
